# 用金額找單據

放款申請、簽核紀錄、傳票查詢、部門分類帳與應收追蹤的搜尋框均可輸入金額。

| 輸入範例 | 比對方式 |
|---|---|
| `1250`、`1,250`、`NT$1,250`、`１，２５０` | 自動處理千分位、幣別與全形數字 |
| `1250.00` | 比對精確金額 1,250 元，小數尾端的零不影響結果 |
| `12.50` | 比對 12.5 元，不會把小數點去除後誤中 1,250 元 |
| `-65.75` | 比對負數金額，保留負號 |
| `水費 1,250` | 同時符合用途文字及金額 |

不含小數點的數字也保留部分比對，例如 `1250` 可找到 `12500`，也可能符合單號或文字。需要精確金額時可輸入 `1250.00`。金額使用原始數值比對，不使用畫面四捨五入後的整數。

搜尋仍套用目前法人、部門、日期、狀態與本人存取權限。已簽核紀錄由後端在本人曾參與的歷史資料中搜尋，搜尋完成後才分頁；可依整批合計或單張金額找到批次。其他列表沿用各頁已載入的資料範圍。

應收追蹤可比對原始、已認列、未收、已收、折讓、待確認收款及退款金額。未知或缺少的金額不視為零。搜尋不會更改金額、簽核結果或帳務資料。
