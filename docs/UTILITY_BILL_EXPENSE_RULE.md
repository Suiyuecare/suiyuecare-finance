# 水費與電費帳單的費用處理

本次依使用者指定的公司作業方式：辨識為水費或電費的明細，以帳單總額列費用，進項稅額固定為 0。這是系統的費用處理規則，不宣稱帳單在法規上屬於免稅交易。

例如水費 136 元會保存為費用 136 元、進項稅額 0 元、總額 136 元。電費 1,050 元也維持總額 1,050 元，不再拆為 1,000 元與 50 元。銀行手續費照既有規則另行計算。

辨識逐筆採用品項／明細文字，不根據整張申請目的或 `6202 水電瓦斯費` 科目判定。水費、電費及水電費可適用；瓦斯、郵電、工程、修繕、維修、安裝、材料、設備、補助、飲水機與電腦等複合用途不會自動套用。混合申請中的其他品項保留原本稅額。

申請表、OCR 金額整理、覆核畫面與傳票產生使用一致的規則。水電明細的稅額欄唯讀；修改費用或總額時保持費用等於總額。舊 OCR 的未稅單價不會因重新輸入數量而降低帳單總額。

既有人工覆核金額會保留到下一次明確覆核，保存更正時追加含原值、新值與操作者的紀錄。已入帳傳票保持原有會計明細。資料庫對申請單權威資料中新增／更改的水電會計列、更正提案及新入帳傳票另做檢查；若舊瀏覽器仍帶入正稅額，會阻擋並提示回會計覆核，整筆交易不會部分保存。

含水電的預支核銷依會計覆核明細逐筆認列科目與稅額，保留暫付款沖銷及多退少補分錄。明細合計不同於最後實支金額時，會在取得傳票編號前停止並提示核對。

驗證涵蓋：一般品項與水電的雙向切換、OCR、明確零總額、歷史人工紀錄、混合申請、主管按核准的實際交易準備、資料庫拒絕／通過案例、預支／採購入帳，以及桌機和手機畫面。發布走固定版本的資料庫演練、原子提交及前台候選版本推廣流程。
