# 財務報表與應收追蹤操作

## 看公司、部門經營情形

1. 開啟「財務報表」，選公司與月份、季度或年度。
2. 切換資產負債表、綜合損益表、現金流量表；可比較前期或去年同期。
3. 「公司與部門」同時顯示收入、直接成本費用、分攤前後損益、預算差異、期末未收與逾期款。未收包含以前月份尚未結清的款項。
4. 行政、共同費用等單位先設為成本／共同費用中心，以費用與預算節餘判讀。成本中心的預算差異為正數表示節餘。
5. 點科目「來源」或部門「明細」追溯完整分錄，再開啟憑證。

## 建立公司報表設定

有公司設定權限的主管，從「公司報表設定」逐法人確認會計準則、401／403、統編、稅籍、申報頻率與申報方式。未知欄位保留待設定。會計可在已授權範圍核對憑證與申報期調整；修改公司基本設定依既有權限辦理。

「科目分類、預算與底稿」可設定科目分類與其他綜合損益、成本中心、逐月預算、共同費用分攤及公司間消除底稿。草稿不套用；覆核狀態須填原因並留下版本歷程。分攤／消除用於管理試算，不改寫各法人的原始分錄。

多人同時編輯發生版本衝突時，原表單內容會保留；先重新讀取最新設定再核對。切換帳號或權限後，請重新開啟表單。

## 401／403 工作底稿

1. 先選單一公司，再切換「401／403」。
2. 依公司的申報頻率組成申報期間，核對銷項、進項憑證以及原始金額、課稅別、用途和扣抵分類。
3. 依實際資料填入期初留抵、年度調整等申報期資訊，處理「缺項與核對事項」。空白不等於零。
4. 水電仍依已設定的公司作業全額列費用；原始憑證稅額與帳上進項稅分開記錄，不把原始憑證稅額擅改成零。
5. 匯出 Excel 工作底稿，或使用「列印／PDF」另存 PDF。欄碼對應官方表單，產出不代表已向財政部申報。

## 應收、部分收款與追款

「應收追蹤」可選公司、資料截止日及部門，依未結清、逾期天數、缺到期日篩選，並搜尋客戶或單號。餘額依已認列分錄、沖減、折讓及正式收款計算；待確認收款另列，不會先當已收。

在「明細／追款」開啟原發票、附件與傳票。會計可輸入本次實收金額及日期並附收款證明，部分收款送審後，由有權主管核對確認。到期日與追款紀錄可記錄負責人、最近聯繫、下次日期及備註；未填真實到期日的款項會列為待補，不會自動假設30天。

退款事件可以分次登錄，系統檢查目前剩餘退款額與重送識別。「目前退款進度」顯示實際操作進度，不隨歷史報表截止日回溯。銀行部分核銷只扣已核銷部分，剩餘金額仍列待核銷。

## 報表狀態與權限

分類帳或公司設定未完整載入時，不提供可被誤認為完整的報表金額。正式帳務尚需確認期初餘額、銀行及稅務勾稽、其他綜合損益適用性與月結。設定的覆核註記只記錄核對狀態，不會自動產生期初或結帳分錄。

全部法人加總與消除後管理試算分別呈現，不代表法定合併財報。帳號依本人既有權限存取，所有設定及帳務操作仍受後端授權與版本檢查保護。
