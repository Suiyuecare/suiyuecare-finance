## 效能驗收

同一部機器使用冷快取、150ms RTT、4Mbps 下載、CPU 4 倍降速、390px 視窗。計時點為登入區可見且登入函式可用，不以骨架／載入提示提早宣告完成。

既有版本三次為 4.05、6.29、3.63 秒。首輪改善後為 2.34–2.38 秒；加入建置後十頁導覽驗收再次量測為 2.41–2.42 秒。後續查到外部 SDK CDN 連線可阻塞就緒，改用同站固定 SDK 後，在其他測試負載停止的相同冷讀條件下為 2.348、2.355、2.363 秒。保留全部慢樣本與逐資源診斷於 [同站 SDK 驗證紀錄](finance-startup-sdk.md)。這是受控量測，不能保證所有真實網路／裝置的等待時間。

```sh
FINANCE_BUILD_TARGET=local pnpm build
node scripts/check_startup_bundle_browser.cjs --measure
```

原始輸出位置可由 FINANCE_STARTUP_EVIDENCE_DIR 指定。一般 CI 只驗證資產數量、真初始化與實際導覽；實際 CDN／網路的秒數另記錄，不用不穩定的公網延遲製造假紅燈。
