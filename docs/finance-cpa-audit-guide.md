# 會計師查帳與簽證準備指南

資料查核日期：2026-09-11。適用於財務人員準備資料、管理階層覆核，以及與受委任會計師確認工作範圍。本指南將官方規範轉為系統與作業建議；各項是否適用、抽樣範圍、重大性及結論，仍由受委任會計師依案件決定。

## 先確認委任目的與法人範圍

| 項目 | 財務報表查核簽證（財簽） | 營利事業所得稅查核簽證（稅簽） |
| --- | --- | --- |
| 核心目的 | 就財務報表是否依適用編製架構允當表達，取得足夠及適切證據後出具查核意見。 | 依所得稅法令及簽證規定查核所得稅申報，核對帳載結果與稅務調整。 |
| 工作成果 | 特定法人／集團、期間、編製架構及版本的財務報表與會計師查核報告。 | 特定納稅義務人及年度的簽證申報資料、查核報告及附件。 |
| 系統應分別保存 | 四表與附註、比較期間、查核差異、證據、管理階層聲明及正式報告。 | 帳載金額、加減項、法令依據與年度、申報金額、申報收件及核定狀態。 |
| 不可混同 | 報表產出、內部覆核或借貸平衡，不等於完成查核簽證。 | 稅簽不等於財簽；營業稅 401／403 申報也不等於營利事業所得稅簽證。 |

法定簽證義務須依法律形式、主管法規及個別事實判斷，不能只看品牌、部門名稱或系統角色。財簽工作參照[金管會查核簽證規則](https://law.fsc.gov.tw/LawContent.aspx?id=FL021144)及適用審計準則；稅簽則依[財政部所得稅簽證辦法](https://law-out.mof.gov.tw/LawContent.aspx?id=FL005941)。帳務處理與稅法有差異時，應保留帳載數並另列申報調整，見[所得稅查核準則](https://law-out.mof.gov.tw/LawContent.aspx?id=FL006027)。

### 長照多法人與管理報表的邊界

- 先列各法人全名、統一編號、法律形式、主管機關、服務機構／分支與部門對應、銀行帳戶、稅務身分及採用的會計架構。同一品牌或同一主管，不足以認定為同一納稅義務人。
- 不應因「長照」或「社團法人」就標為所得免稅。財政部對非公益性質長照社團法人已有[營利事業課稅適用說明](https://law-out.mof.gov.tw/LawContent.aspx?id=GL011505)。
- 營業稅免稅須依服務、法源及契約條件逐項確認。例如[政府特約長照交通接送免徵營業稅說明](https://www.mof.gov.tw/singlehtml/384fb3077bb349ea973e7fc6f13b6974?cntId=e15c73c78df442be8de6d91e604edaba)，不能擴張為機構全部收入均免稅，更不能推論所得稅免稅。
- 公司／部門損益加總可作管理分析；要標示參與法人、期間、分攤與消除規則。是否編製合併或其他集團財務報表，須另依編製架構判斷；共同品牌加總不能直接命名為已簽證合併報表，也不能據此合併申報所得稅。[TWSA600](https://www.ardf.org.tw/ardf/2025/600.pdf)處理集團查核責任，不取代編製範圍的判斷。

## 十二項查帳準備控制

以下都是準備及覆核方法，不能以勾選完成替代查核證據。財簽、稅簽均可採用，但 A11 以稅簽為主，A10、A12 依案件及報告範圍調整。

| ID／重點 | 建議查帳方法 | 應準備資料與系統紀錄 |
| --- | --- | --- |
| A01 案件與法人範圍 | 逐一確認受查者、納稅義務人、期間、財簽／稅簽、編製架構及比較期間；由會計師確認適用項目。 | 登記／立案資料、統編、法律形式、股權或控制關係、部門對應、委任書、負責人及資料窗口。 |
| A02 完整母體與封存版本 | 核對試算表、總帳、明細帳與期初銜接；記錄資料截止時間、筆數及借貸合計，確認分頁已全部讀取；來源變更後重新核對。 | 年度與比較期試算表、完整總帳、各明細帳、前期已核定／已查核報表、期初調整、匯出版本與來源指紋。 |
| A03 索資與證據鏈 | 從報表追到科目、傳票及原始憑證，亦由憑證反查入帳；記錄抽樣項目、程序、結果及覆核人。 | 合約、發票／收據、驗收或服務紀錄、付款證明、附件版本、提供者、查核人／日期、差異及處理依據。上傳狀態與查核結論分開。 |
| A04 人工分錄與控制踰越 | 檢視期末、回溯、異常科目、同人建立及覆核、沖銷與重分類；核對授權、理由及前後值。異常清單用於選樣，不直接指稱舞弊。 | 原始分錄、人工更正歷史、簽核與權限歷史、調整理由、支持憑證、沖銷對應及期末調整清單。 |
| A05 銀行核對與外部函證 | 逐帳戶核對銀行結單與帳載；列未達帳項及期後清理。由會計師控制函證對象、寄送與直接回函，另記未回函、差異及替代程序。 | 銀行帳戶完整清冊、結單、調節表、借款／擔保資料；函證程序紀錄與直接回函。公司自行上傳文件不自動標為獨立函證。 |
| A06 長照收入與應收可回收性 | 以服務期間及契約核對收入、請款與核定；逐筆核對收款、折讓及退款，檢查帳齡及期後收款，評估備抵假設。 | 服務契約、履約／照顧紀錄、付款人或補助機關、請款及核定資料、應收明細、實際到期日、爭議與催收、期後收款及估計方法。 |
| A07 截止與未入帳負債 | 抽查期末前後服務、交貨、驗收、發票及付款；核對未到單、薪資、租金等應計及預付，檢查次期沖回。沒有申請單不代表沒有負債。 | 期末前後憑證、未到單／未請款清單、合約、薪資明細、驗收日期、應計計算、期後付款與沖回傳票。 |
| A08 資產、租賃與盤點底稿 | 將期初、增添、處分與折舊銜接期末；核對權利、租約、耐用年限與減損；存貨如適用，留存盤點、差異及調節。 | 資產／存貨台帳、取得及處分文件、權狀或使用權資料、租約、折舊計算、盤點紀錄與差異說明。照片本身不足以證明完整性或所有權。 |
| A09 關係人及跨法人往來 | 核對關係人名冊及雙方餘額；檢查借貸、代墊、租賃、服務價格與授權；消除須有雙邊來源及理由，差異先列待核對。 | 控制及親屬等關係資訊、借貸與交易契約、董事會等決議、雙邊對帳、期末餘額、分攤依據、消除分錄及相關附註。 |
| A10 四表、權益調節與附註 | 核對四表互相銜接及比較數；權益以期初、損益／其他綜合損益、出資／分配與調整調節至期末；建立附註索引。未知事項列待補，不填假零。 | 資產負債表、綜合損益表、權益變動表、現金流量表、附註及比較資料；出資、盈餘分配與其他決議、相關傳票、會計政策及重大估計。 |
| A11 帳稅差異與申報核對 | 自帳載稅前結果逐項調節至課稅所得；分別核對永久性／暫時性差異、扣繳、虧損及適用年度。保留稅務調整，不直接覆寫財務帳。 | 申報書及收件回執、加減項底稿與法源、憑證、扣繳及繳稅證明、歷年核定、虧損扣抵支持資料；營業稅與所得稅資料分開。 |
| A12 結案聲明、期後事項與繼續經營 | 彙整未更正差異、期後事件及現金預測；由適當管理階層具名聲明，確認期間與日期；正式會計師報告獨立留存。 | 管理階層聲明、期後董事會等紀錄、訴訟／承諾／擔保、重大期後收付款、至少涵蓋適用評估期間的預測及到期債務、未更正差異與正式報告。 |

### 四表與附註不可省略

採企業會計準則者，完整財務報表包括四表及附註，並應依規定提供比較資訊；實際表名與內容仍依適用架構與法律形式調整。[企業會計準則第二號](https://ifrs.sfb.gov.tw/ardf/eas02-3.pdf)是此處的重要依據。僅有三張試算報表或部門損益，不能標為完整財務報表；附註也不能只產出沒有支持資料的通用文字。會計政策需帶適用版本及生效期間，不能把尚未生效的新準則默認套入歷史年度。

## 狀態、責任與系統證明的限制

建議至少區分「待提供」、「已提供」、「待查核」、「已由具名人覆核」、「不適用（附理由）」與「來源變更須重核」。每次覆核綁定案件、期間、來源版本、範圍、覆核人及時間。修改或補件後保留歷史，重新判斷受影響的覆核。

系統可證明有哪些資料、誰在何時提供或覆核哪個版本，以及哪些差異仍未處理；不能自動證明交易真實、母體完整、憑證適當、估計合理、沒有舞弊、會計師獨立性或最終查核意見。管理階層聲明是查核所需的一種證據，不能單獨替代其他足夠及適切證據。即使核對數字一致，也不應顯示「已簽證」或「會計師已確認」，除非有該範圍及版本的正式報告可核對。

## 本輪系統實作與驗證

入口：財務報表 → 會計師查帳。先選擇單一法人與年度、季度或月份；全部法人管理加總不能當成受查法人。

- **十二項資料清單**：每項保留負責人、期限、佐證位置／檔名版本、來源申請或發票、適用性、說明與保存理由。
- **準備與內部覆核分工**：後端記錄實際帳號及時間；同一準備人不能覆核自己提供的項目，未確認適用性不能完成覆核。修改內容或來源版本變更須重新核對。
- **十項系統核對**：完整筆數、逐傳票借貸、重複／缺來源、日期金額、資產負債、現金、科目部門、應收控制科目、帳齡、期末人工分錄候選。未取得的資料保留未知；這些候選不是會計師抽樣結論。
- **權益調節底稿**：期初、本期損益、OCI、其他權益變動與結帳影響勾稽，避免已結轉金額重複加計；須另完成分類、決議佐證與附註，才是完整報表準備。
- **Excel 與來源索引 JSON**：同時提供科目試算表、完整已讀取分類帳索引、核對事項、資料清單、內部覆核及三表暫編數。畫面搜尋不會刪減匯出母體。JSON 帶內容 SHA-256 供檔案一致性核對，未內含附件檔案。
- **來源與保存保護**：前後讀取來源指紋，確認來源沒有在讀取期間變動；保存需精確版本及來源一致，每次修改寫入不可直接改寫的版本歷程。介面提供最近 100 筆歷程。指紋不等於鎖帳、不可變封存或附件真實性驗證。
- **既有合規畫面修正**：關帳、憑證索引、年度內部覆核只有後端確認保存後才更新畫面；操作紀錄保存失敗不再留假成功紀錄。原稱封存的件數紀錄改稱索引，缺附件的申請、發票、繳費單也列入。

外審與董事保持唯讀，仍須具備該公司每筆來源的既有調閱權；角色名稱本身不會擴大資料權限。沒有完整來源權限時，應由已授權會計人員整理及匯出受查範圍。

驗證：`pnpm test:audit-readiness` 涵蓋實際計算、真 PostgreSQL RPC／權限／來源衝突／兩人覆核／回滾、前端非同步與舊合規保存。`pnpm test:audit-readiness-browser` 以匿名虛構公司及單據測試桌機 1440、手機 390、實際 Excel／JSON 下載、版本衝突與唯讀表單。完整發布仍須通過專案 release gates、受保護的資料庫發布與正式站回讀。

上面的十二項清單是作業指引與資料協作功能，不代表十二項查核程序已由系統自動完成，也不代表任何正式案件已獲簽證。
