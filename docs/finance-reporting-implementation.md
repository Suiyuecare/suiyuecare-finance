# 財務報表與應收改善

基準：正式版本 0af02a4，2026-09-10 使用者同意前一輪評估方案並授權實作。

## 範圍

1. 修正月底截止、累計未結轉損益、收入沖減、現金流分類與內部互轉；完整分頁及一致來源追溯。
2. 報表工作區提供公司／期間、比較期間、資產負債、綜合損益、現金流、401／403工作底稿及 XLSX／列印 PDF。
3. 公司／部門損益展示直接費用、受覆核分攤、預算差異、成本中心及有依據的公司間消除；未設定不能當零或自動核准。
4. 應收工作區依正式分錄關聯計算折讓、實收、未收，支援部分收款、分次退款、正式到期日及追款紀錄。
5. 稅務與管理設定須持久化、版本校驗、審計及後端授權；水電全額列費用規則保持，原始憑證稅額另存。

## 驗收

- 虛構資料重現並修正八項已知問題，檢查跨月／跨年、已結轉、借貸平衡及不完整資料狀態。
- SQL 本地執行涵蓋金額、狀態、併發版本、冪等、拒絕未授權、回滾及正式資料指紋。
- 桌機1440、手機390實際畫面及操作；相同虛構資料的前後對照、無整頁水平溢出、44px操作區、鍵盤焦點、載入及錯誤狀態。
- 匯出為真 XLSX 及可列印報表；金額與同範圍畫面一致，稅表標示工作底稿並列缺項與官方欄位來源。
- 所有既有 release gates 通過，固定 migration 批次走既有 protected production release，驗證 production manifest／hash／頁面及資料庫 postflight。

## 明確界限

未提供的401／403申報類型、期初餘額、分攤依據、預算、OCI適用性及月結覆核，保留待設定／暫編。產生預填底稿不代表已向財政部申報。全部法人加總與消除後管理底稿分別標示。實作及測試不代表曾以每位員工的真實Google帳號登入。
